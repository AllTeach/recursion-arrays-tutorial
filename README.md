# 📚 מדריך רקורסיה על מערכים - כיתה יא

ברוכים הבאים למדריך המלא על **רקורסיה על מערכים חד-ממדיים**.

מדריך זה מיועד לתלמידים שכבר למדו את יסודות הרקורסיה (רקורסיה הלוך, חזור, הלוך-חזור) ועכשיו רוצים להעמיק בעבודה עם מערכים.

## 📖 תוכן המדריך

### 1️⃣ [01_Theory.cs](./01_Theory.cs)
- **הסבר תאורטי מלא** על רקורסיה על מערכים
- עיקרון ההנמקה - מתי עוצרים, מה המטרה
- דוגמאות בסיסיות עם הערות מפורטות
- פתרונות ראשונים ללא wrapper

### 2️⃣ [02_Arrays_Basic.cs](./02_Arrays_Basic.cs)
- פעולות בסיסיות **ללא wrapper**
- קבלת מערך ואינדקס כפרמטר
- חיפוש, סכום, מקסימום, מינימום וכו'
- כל פתרון מלא עם הסבר שלב אחרי שלב

### 3️⃣ [03_Arrays_Advanced.cs](./03_Arrays_Advanced.cs)
- השימוש ב-**Wrapper Functions**
- הסתרת האינדקס מהמשתמש
- ממשק נקי וקל לשימוש
- היתרונות של wrapper

### 4️⃣ [04_Exercises_Guided.cs](./04_Exercises_Guided.cs)
- **תרגילים עם הכוונה** (skeleton code)
- השלמות קוד
- תיאור הבעיה וכיוון לפתרון
- ללא פתרון מלא - כדי שהתלמיד יחשוב

### 5️⃣ [05_Exercises_Full.cs](./05_Exercises_Full.cs)
- **פתרונות מלאים** לכל התרגילים
- הסברים מפורטים
- דרכי חשיבה חלופיות

### 6️⃣ [06_Original_Examples.cs](./06_Original_Examples.cs)
- הקובץ המקורי שלך עם כל הדוגמאות על מספרים שלמים
- בתור ייחוס והשוואה

---

## 🎯 כיצד להשתמש בחומר?

### לתלמידים שרוצים ללמוד בעצמם:
1. התחילו ב-**01_Theory** - קראו בעיון את ההסברים
2. עברו ל-**02_Arrays_Basic** - בחנו כל פתרון
3. כשמרגישים בטוחים - **04_Exercises_Guided** - נסו להשלים קוד
4. בדקו את **05_Exercises_Full** - השוו את הפתרונות שלכם

### למורים שמלמדים:
1. הצגו את **01_Theory** בשיעור
2. פתרו ביחד דוגמאות מ-**02_Arrays_Basic**
3. תנו לתלמידים **04_Exercises_Guided** בעבודה עצמית/בקבוצות
4. סיכום בשיעור הבא עם **05_Exercises_Full**

## 🔑 מושגים מרכזיים

### תנאי העצירה (Base Case)
```
if (index == array.length) // סיימנו את כל המערך
    return [מה שצריך]
```

### הנחה (Hypothesis)
"אנחנו מניחים שהפונקציה עובדת כבר אחד משמאלה/ימינה"

### צעד רקורסיבי (Recursive Step)
"איפה אנחנו קוראים לעצמנו בעיגול חדש?"

---

## 💡 טיפים חשובים

1. **הסתרו את האינדקס** - ברגע שתלמידים שולטים, השתמשו ב-wrapper functions
2. **צייר דיאגרמה** - מערך + אינדקס + call stack
3. **שימו דגש על הנחה** - לא בדוקה את כל המערך כראש, רק על מה שלפני
4. **בדקו edge cases** - מערך ריק, מערך בגודל 1
